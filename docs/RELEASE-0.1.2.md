ScreenTask Mac 0.1.2 加入全新 macOS 應用程式圖示：兩台螢幕與無線傳送弧線，代表在區域網路分享畫面。圖示包含 16–1024 px 完整 `.icns` 尺寸集，可在 Finder、Dock、Spotlight 與應用程式資料夾顯示。

下載 `ScreenTaskMac-0.1.2-arm64.zip`，解壓縮後將 App 拖到「應用程式」。首次開啟請允許螢幕錄製及區域網路連線，再重新開啟程式。

本版保留瀏覽器觀看、私人帳密、多螢幕來源選擇、JPEG 品質與間隔、游標、選單列、自動開始／最小化、全螢幕及斷線重連。

發行包使用 ad-hoc 簽署，尚未經 Apple 公證。若 Gatekeeper 阻擋，確認來源後使用系統設定的「仍要打開」。HTTP 未加密，請在可信任網路使用。詳見 `docs/VALIDATION.md`。

GPL-3.0-or-later。致謝 EslaMx7/ScreenTask 原始專案；本專案是獨立 macOS 移植。
